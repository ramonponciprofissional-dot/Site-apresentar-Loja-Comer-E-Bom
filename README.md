# Site Comer É Bom

Site institucional em HTML e CSS para apresentar a marmitaria Comer É Bom.

## O que o site tem

- Seção **Sobre Nós**, apresentando a loja
- **Mapa de localização**
- **Botão de pedido**, que leva o cliente à página de pedidos no Beacons

## Tecnologias

- HTML
- CSS

## Como ver o projeto

1. Clone o repositório:
   ```bash
   git clone https://github.com/ramonponciprofissional-dot/Site-apresentar-Loja-Comer-E-Bom.git
   ```
2. Abra o arquivo `index.html` no navegador. [CONFIRMAR o nome do arquivo principal]
